# Laundry Mart Login Page

## Project Description

This project is a simple Laundry Mart login page created using HTML and CSS.

The page uses a split layout. The left side contains a laundry-related image, while the right side contains a login form.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox

## Features

- Full-screen login layout
- Split-screen design
- Laundry-themed image
- Email input field
- Password input field
- Forgot Password link
- Login button
- Register Now link
- Responsive viewport setup
- Clean and simple user interface
